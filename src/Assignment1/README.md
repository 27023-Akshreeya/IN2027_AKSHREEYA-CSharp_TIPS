# Contact Manager

## Description
- This console has the following functionalites
- 
MENU
[A]dd contact
[S]earch contact
[V]iew all contact
[E]dit contact
[R]emove contact
[C]lose contact

### Add contact 
- adds contact
- doesnt allow duplicates
- handles null , and empty inputs
- allows only valid inputs

### Search contacts
- searches if contact exits and displays details

### view contacts
- views all the contact 
- gives detailed display

### Remove contacts
- Remove contact by index
- displays final list

### Edit
- allows editing contact
- can edit name, phone number, email address, additional notes
