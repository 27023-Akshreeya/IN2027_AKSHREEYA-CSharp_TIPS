# Assignment 2 - C# OOP Console Applications
 
## Overview
 
This assignment contains three C# console applications developed to practice Object-Oriented Programming (OOP) concepts. Each task focuses on using inheritance, abstraction, polymorphism, and a simple project structure.
 
## Tasks
 
### Task 1 – Shape Hierarchy
A console application that calculates the area of different shapes.
 
**Features**
- Calculate the area of a Rectangle
- Calculate the area of a Circle
- Input validation
- Menu-driven interface
 
---
 
### Task 2 – Employee Hierarchy
A console application to calculate employee bonuses based on their role.
 
**Features**
- Add employee details
- Supports Manager and Developer roles
- Bonus calculation
- Input validation
 
---
 
### Task 3 – Banking System
A console application that performs basic banking operations.
 
**Features**
- Create Savings and Checking accounts
- Deposit money
- Withdraw money
- Display account details
- Input validation
 
## Project Structure
 
Each task follows a simple layered structure:
 
- **ConsoleService** – Controls the application flow.
- **Model** – Contains classes and business logic.
- **View** – Handles user interaction.
- **Repository** – Stores account data (used in Banking System).
- **Helper** – Contains validation methods
